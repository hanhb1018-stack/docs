GregAPI 对外提供三类接口，分别面向不同的调用场景。不确定从哪开始，按下面的分工对号入座即可。

## 基础地址

```bash
export BASE_URL="https://www.gregapi.com"
```

所有能力共用同一个域名与同一个 API Token，路径按协议区分。完整路径前缀、鉴权方式与异步任务范式见 [通用约定](/api-reference/common)。

## 三类接口的分工

| 接口 | 用什么凭证 | 解决什么问题 | 从哪开始 |
|---|---|---|---|
| 模型调用 API | 模型调用 Token | 访问 `/v1/*`、`/volcark/*`、`/minimaxi/*`、`/vidu/*` 等路径，调用文本、图像、视频、语音能力 | [API 参考](/api-reference/introduction) |
| 账号与控制台 API | 个人资料访问令牌 | 读取自己的余额、个人资料等控制台数据 | [余额接口](/balance-api) |
| 查询授权 API | 查询授权 Token | 给外部系统签发只读 Token，查询余额、日志、异步任务、客户价格等运营数据 | [查询授权](/query-authorization) |

三类凭证的获取方式与权限范围见 [API 认证](/authentication)。
