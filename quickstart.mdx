按下面三步，5 分钟内就能跑通第一条请求。本页示例全部可直接复制执行，只需要替换 Token 和模型名。

<Steps>
  <Step title="注册与登录">
    访问 [www.gregapi.com](https://www.gregapi.com/) 注册账号并登录控制台，确认个人资料与初始权限。
  </Step>
  <Step title="创建 API Token">
    进入控制台「个人资料」创建模型调用 Token，复制保存。Token 只在创建时完整显示一次。
  </Step>
  <Step title="发起第一次调用">
    用下面的示例替换 `$TOKEN` 执行，确认能拿到返回结果。
  </Step>
</Steps>

## 准备环境

```bash
export BASE_URL="https://www.gregapi.com"
export TOKEN="oh-xxxxxxxxxxxxxxxx"
```

## 调用文本模型

<CodeGroup>
```bash cURL
curl -X POST "$BASE_URL/v1/chat/completions" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "用一句话介绍你自己"}]
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(base_url="https://www.gregapi.com/v1", api_key="oh-xxxxxxxxxxxxxxxx")
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)
print(resp.choices[0].message.content)
```

```js Node.js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://www.gregapi.com/v1",
  apiKey: "oh-xxxxxxxxxxxxxxxx",
});
const resp = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "用一句话介绍你自己" }],
});
console.log(resp.choices[0].message.content);
```
</CodeGroup>

模型名请换成控制台「模型广场」中你已开通的模型，完整清单与参数见 [大语言模型接口](/api-reference/texts/openai/chat-completions)。

## 调用图像模型

```bash
curl -X POST "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只戴墨镜的橘猫，扁平插画风格",
    "size": "1024x1024"
  }'
```

详见 [GPT 生图](/api-reference/images/overview) 与 [Seedream 生图](/api-reference/images/doubao-seedream-5-0)。

## 调用视频模型

视频是异步任务：先创建，再轮询结果。

```bash
# 1. 创建任务
curl -X POST "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-0-manju-special",
    "prompt": "雨夜长街上人物回眸，镜头缓慢推近",
    "params": {"aspect_ratio": "9:16", "duration": "5", "mode": "text-to-video"}
  }'

# 2. 用返回的 task_id 查询
curl "$BASE_URL/v1/video/generations/{task_id}" \
  -H "Authorization: Bearer $TOKEN"
```

更多视频模型见 [视频模型接口](/api-reference/videos/seedance2)。

## 上线前检查

- 确认已开通模型、额度与计费口径，避免上线后才发现额度不足。
- Token 只放在服务端环境变量里，不要写进前端代码或公开仓库。
- 用 [请求 ID](/request-id) 串联日志，用 [使用日志](/console) 核对调用记录与费用。
