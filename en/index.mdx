## Welcome to the GregAPI platform

GregAPI provides a unified multi-model, multi-capability API gateway. With a single account and one unified token, you can access text, image, video, speech, and other generative capabilities. This documentation helps you get started quickly and become proficient with the console, billing, security, and support workflows.
