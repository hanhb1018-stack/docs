GregAPI provides a unified multi-model, multi-capability API gateway. With a single account and one unified token, you can access text, image, video, speech, and other generative capabilities. This documentation is for platform users and helps you get started quickly and become proficient with the console, billing, security, and support workflows.

## Recommended path

<Steps>
  <Step title="Make your first request">
    See [Quickstart](/en/quickstart) to get your first response in five minutes.
  </Step>
  <Step title="Understand how the APIs are split">
    Read [API overview](/en/api-overview) and [Common conventions](/en/api-reference/common) to pick the right protocol and authentication method.
  </Step>
  <Step title="Look up API docs by capability">
    Go to [API reference](/en/api-reference/introduction) and drill down by text, image, video, and audio.
  </Step>
  <Step title="Reconcile billing and self-serve issues">
    Billing and reconciliation are covered in [Billing basics](/en/quota-billing); report issues via [Support and tickets](/en/support).
  </Step>
</Steps>
