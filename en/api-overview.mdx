GregAPI exposes three common categories of interfaces, each targeting different calling scenarios.

## Base URL

```bash
export BASE_URL="https://api.gregapi.com"
export TOKEN="your model token"
```

## Common capabilities

- **Model API**: use a model token to access model paths such as `/v1/*`, `/minimaxi/*`, `/kling/*`, `/vidu/*`, and `/volcark/*`, covering OpenAI-compatible, MiniMax, Kling, Vidu, Volcano Ark, and Gemini protocols.
- **Account & console API**: use a profile access token to access `/api/user/*` and query account balance, profile, and other console data.
- **Query authorization API**: use a query authorization token to access `/api/query/v1/*` for read-only queries of balance, logs, async tasks, users, customer pricing, channels, and other operational data.
