## Capability categories

| Category | Description |
|---|---|
| Large Language Models (LLM) | Text generation and chat completion, with multiple interface styles (classic chat, responses, and native generation) |
| Image Models | Text-to-image, image editing, multi-reference and group generation, and async image tasks |
| Video Models | Text-to-video, image-to-video, first/last-frame and reference-material generation |
| Speech Models | Speech synthesis and voice customization (quick voice cloning) |

## Common conventions

### Base URL

```bash
export BASE_URL="https://www.gregapi.com"
```

### Authentication

All requests carry the platform API Token in the request header:

```http
Authorization: Bearer <TOKEN>
Content-Type: application/json
```

Get your Token from the console and bind it to the relevant capability channels.

### Request styles

- Synchronous: a single request returns the result directly.
- Asynchronous: create a task first, then poll the query endpoint for results; commonly used for video, image, and speech synthesis workloads.
