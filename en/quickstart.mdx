Follow the three steps below to make your first request in five minutes. Every example on this page can be copied and run directly — you only need to replace the token and the model name.

<Steps>
  <Step title="Sign up and log in">
    Go to [www.gregapi.com](https://www.gregapi.com/) to register an account and log in to the console, then confirm your profile and initial permissions.
  </Step>
  <Step title="Create an API token">
    In the console, open Profile and create a model-calling token, then copy and save it. The full token is shown only once at creation time.
  </Step>
  <Step title="Make your first call">
    Replace `$TOKEN` in the examples below and run one to confirm you get a response.
  </Step>
</Steps>

## Prepare your environment

```bash
export BASE_URL="https://www.gregapi.com"
export TOKEN="oh-xxxxxxxxxxxxxxxx"
```

## Call a text model

<CodeGroup>
```bash cURL
curl -X POST "$BASE_URL/v1/chat/completions" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Introduce yourself in one sentence"}]
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(base_url="https://www.gregapi.com/v1", api_key="oh-xxxxxxxxxxxxxxxx")
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Introduce yourself in one sentence"}],
)
print(resp.choices[0].message.content)
```

```js Node.js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://www.gregapi.com/v1",
  apiKey: "oh-xxxxxxxxxxxxxxxx",
});
const resp = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "Introduce yourself in one sentence" }],
});
console.log(resp.choices[0].message.content);
```
</CodeGroup>

Replace the model name with one you have enabled in the console's model gallery. For the full list and parameters, see [LLM APIs](/en/api-reference/texts/openai/chat-completions).

## Call an image model

```bash
curl -X POST "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "An orange cat wearing sunglasses, flat illustration style",
    "size": "1024x1024"
  }'
```

See [GPT image generation](/en/api-reference/images/overview) and [Seedream image generation](/en/api-reference/images/doubao-seedream-5-0) for details.

## Call a video model

Video is asynchronous: create a task first, then poll for the result.

```bash
# 1. Create the task
curl -X POST "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-0-manju-special",
    "prompt": "A character looks back on a rainy street at night, camera slowly pushes in",
    "params": {"aspect_ratio": "9:16", "duration": "5", "mode": "text-to-video"}
  }'

# 2. Query with the returned task_id
curl "$BASE_URL/v1/video/generations/{task_id}" \
  -H "Authorization: Bearer $TOKEN"
```

For more video models, see [Video model APIs](/en/api-reference/videos/seedance2).

## Pre-launch checks

- Confirm the enabled models, quota, and billing rules so you do not discover a quota shortfall after launch.
- Keep the token in a server-side environment variable only; never put it in front-end code or a public repository.
- Use the [Request ID](/en/request-id) to correlate logs, and check call records and costs in [Usage logs](/en/console).
