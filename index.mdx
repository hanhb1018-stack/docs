GregAPI 提供统一的多模型、多能力 API 网关，通过一个账号与统一的 Token 即可调用文本、图像、视频、语音等各类生成能力。这里是面向平台用户的使用文档，帮助你快速上手，熟练使用控制台、账单、安全与支持流程。

## 推荐动线

<Steps>
  <Step title="跑通第一条请求">
    看 [快速开始](/quickstart)，5 分钟拿到第一条返回结果。
  </Step>
  <Step title="搞清楚接口怎么分">
    看 [API 概览](/api-overview) 与 [通用约定](/api-reference/common)，确定用哪套协议、怎么鉴权。
  </Step>
  <Step title="按能力查接口文档">
    进 [API 参考](/api-reference/introduction)，按文本、图像、视频、语音逐级定位。
  </Step>
  <Step title="对上账、出问题能自助">
    计费与对账见 [计费原理](/quota-billing)，报障见 [支持与工单](/support)。
  </Step>
</Steps>
