## 欢迎使用 GregAPI 平台

GregAPI 提供统一的多模型、多能力 API 网关，通过一个账号与统一的 Token 即可调用文本、图像、视频、语音等各类生成能力。这里是面向平台用户的使用文档，帮助你快速上手，熟练使用控制台、账单、安全与支持流程。
