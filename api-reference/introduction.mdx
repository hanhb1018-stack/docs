title: "API 参考概览"
---

GregAPI 提供统一的多能力生成接口，通过单一网关与同一个 API Token 即可调用文本、图像、视频、语音四类生成能力。以下文档按能力类型组织，方便您快速定位所需接口。

## 能力分类

| 分类 | 能力说明 |
|---|---|
| 大语言模型（LLM） | 文本生成与对话补全，提供多套接口风格（经典对话、响应式与原生生成） |
| 图像模型 | 文生图、图像编辑、多参考图与组图，以及异步图片任务 |
| 视频模型 | 文生视频、图生视频、首尾帧与参考素材等视频生成 |
| 语音模型 | 语音合成与音色定制（快速复刻） |

## 通用约定

### Base URL

```bash
export BASE_URL="https://api.gregapi.com"
```

### 认证

所有请求统一在请求头携带平台 API Token：

```http
Authorization: Bearer <TOKEN>
Content-Type: application/json
```

Token 可在控制台获取，并绑定到相应的能力通道。

### 调用形态

- 同步接口：一次请求直接返回结果。
- 异步任务：先创建任务，再通过查询接口轮询结果，多用于视频、图像与语音合成等耗时场景。
